      Query the dataDaten abfragen

      The data of this site is a Turtle file in the RDF model of Wikibase, so queries written for the Query Service of a Wikibase work here too. Edit a query and press Run.Die Daten dieser Seite liegen als Turtle-Datei im RDF-Modell von Wikibase vor. Abfragen, die für den Query Service einer Wikibase geschrieben sind, laufen deshalb auch hier. Abfrage ändern, dann auf Ausführen klicken.

      The dataDie Daten A Turtle file in the RDF model of Wikibase with 12456 triples:Eine Turtle-Datei im RDF-Modell von Wikibase mit 12456 Tripeln: fuzzy-sl.wikibase.cloud.ttl · Wikibase ontologyWikibase-Ontologie

      Every record on its own:Jeder Datensatz einzeln: each page has a Turtle file in ttl/ and the archived JSON in json/; the catalogue (DCAT) lists them.zu jeder Seite gibt es eine Turtle-Datei in ttl/ und das archivierte JSON in json/; der Katalog (DCAT) verzeichnet sie.

      Press Run to start. The first run takes a few seconds.Auf „Ausführen“ klicken, um zu starten. Der erste Lauf dauert einige Sekunden.

      The first run loads Python (Pyodide) from cdn.jsdelivr.net and rdflib from PyPI; after that everything runs in your browser and what you type does not leave it.Der erste Lauf lädt Python (Pyodide) von cdn.jsdelivr.net und rdflib von PyPI; danach läuft alles in Ihrem Browser, und was Sie eintippen, verlässt ihn nicht.
